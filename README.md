# mentor-quiz-api

## 📄 Техническое задание (ТЗ)

### 📌 Цель

Создать REST API для платформы с квизами, где пользователи могут создавать, проходить и лайкать/дизлайкать тесты. Есть базовая ролевка (юзеры и админы). Используется фронт от Эмилии.

---

### 🧱 Технологический стек

- Язык: Go
- База данных: PostgreSQL
- Migrations: migrate или goose
- SQL-биндинг: sqlc
- Авторизация: JWT (Access + Refresh)
- Валидация: go-playground/validator
- Маршрутизация: chi или gin
- REST API
- Логирование: кастомный логгер или zerolog

---

### 👤 Роли пользователей

| Роль     | Возможности |
|----------|-------------|
| **User** | - Регистрироваться и логиниться  
           - Создавать/удалять/редактировать свои квизы  
           - Проходить любые тесты  
           - Лайкать/дизлайкать тесты |
| **Admin** | Всё, что может User + может удалять и редактировать чужие тесты |

---

### 📦 Сущности и связи

- `User`: id, email, password_hash, role, created_at  
- `Quiz`: id, title, description, author_id, likes, dislikes, created_at  
- `Question`: id, quiz_id, text, type, options (если множественный выбор)  
- `Answer`: id, question_id, text, is_correct  
- `UserQuizResult`: id, user_id, quiz_id, score, total, started_at, finished_at  
- `Like`: user_id, quiz_id, is_like (bool)  

---

### 📚 Эндпоинты (MVP)

#### 🔐 Аутентификация

- `POST /auth/register` — регистрация
- `POST /auth/login` — логин
- `POST /auth/refresh` — обновление access токена
- `GET /auth/me` — получить данные текущего юзера

#### 📘 Квизы

- `GET /quizzes` — список всех квизов (пагинация, поиск)
- `GET /quizzes/:id` — получить квиз с вопросами
- `POST /quizzes` — создать квиз (автор — текущий юзер)
- `PUT /quizzes/:id` — редактировать квиз (если автор или админ)
- `DELETE /quizzes/:id` — удалить квиз (если автор или админ)

#### ✅ Прохождение теста

- `POST /quizzes/:id/submit` — отправить ответы, получить результат

#### 👍 Лайки

- `POST /quizzes/:id/like` — лайк/дизлайк/снять реакцию

---

### 🔎 Параметры поиска и пагинации

Пример: `/quizzes?search=react&page=2&limit=10`
